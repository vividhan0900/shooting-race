# 슈팅 레이스 (Shooting Race)

중3 학생의 게임 기획서 「슈팅 레이스」(스킬을 사용해 레이싱하는 게임)를 바탕으로 만든 HTML 게임 프로토타입 모음입니다. 빌드 없이 브라우저에서 바로 실행됩니다.

| 파일 | 내용 |
|---|---|
| `index.html` | v1 · 기획서 충실 구현 (2D). 차량/스킬 선택 → 매칭 → 3바퀴 레이스 |
| `v2.html` | v2 · 마우스 조준 사격, 4스테이지 토너먼트, 코인 상점·업그레이드, 라이벌, 효과음 |
| `v3-3d.html` | v3 · Three.js 로우폴리 3D 주행 시험판 (인터넷 연결 필요, 스킬/사격 이식 예정) |

## 조작
W/↑ 가속 · S/↓ 브레이크 · A D/←→ 조향 · Shift/Space 드리프트 · Q/E 스킬 · 마우스 조준+클릭 사격(v2) · C 시점(v3) · M 음소거

## 실행
파일을 크롬/엣지로 열면 됩니다. (메모장으로 열면 코드만 보입니다)
